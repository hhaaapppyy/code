# 文析（WenXi）

一个帮助研究生把被动阅读转成主动研究训练的轻量网站。

## 目前具备

- 阅读前术语/缩写预习清单
- 分板块阅读与中英逐句对照切换
- 每一板块的基础与拓展问题，回答后提供反馈再进入下一节
- 句子选中、概念速查、随手笔记
- 完整阅读档案：保留原始回答、系统补充与方法迁移反思（浏览器本地保存）
- TXT、Markdown、PDF 的导入入口（当前为引导流程演示；内容解析待接入）

## 运行

直接用浏览器打开 `index.html`，或使用任意静态服务器。例如：

```bash
npx serve .
```

## 下一步建议

接入 PDF.js 进行真正的 PDF 分页与文字提取；接入大模型服务后，根据具体论文生成术语表、问题与针对性反馈；以账户/云端数据库替换本地存储，实现跨设备档案同步。
