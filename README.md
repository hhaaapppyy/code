# 文析（WenXi）

一个以原文为中心的浏览器本地精读器：先显示论文，再在合适的位置引导研究思考。

## 目前具备

- 本地解析可复制文字的 PDF、TXT、Markdown，并逐句显示原文
- 每句可获取中译；选中英文术语后可查词
- 读完一页/一段后才出现思考停靠点
- 五问总结：研究问题、核心思路、最重要结论、相较前人的贡献、可质疑之处
- 选句笔记、停靠思考与总结均保存于浏览器本地

## 运行

直接用浏览器打开 `index.html`，或使用任意静态服务器。例如：

```bash
npx serve .
```

## 下一步建议

PDF.js、翻译与词典服务通过网络加载；扫描版 PDF 仍需先 OCR。生产版建议接入稳定的翻译服务、专业术语知识库和账户同步。
